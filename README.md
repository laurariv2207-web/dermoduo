# DermoDuo — página web

## Cómo abrirla correctamente
1. Descarga el archivo ZIP completo.
2. En Windows, haz clic derecho sobre el ZIP y selecciona **Extraer todo…**.
3. Abre la carpeta extraída.
4. Abre `index.html` con Chrome, Edge o Firefox.
5. **No muevas `index.html` fuera de la carpeta ni elimines `images`**: las fotografías están en esa subcarpeta y el HTML las carga desde allí.

Estructura necesaria:
- `index.html`
- `images/` (contiene las seis fotografías)
- `README.md`

La encuesta y el panel de interacciones permanecen incluidos. Los datos del panel se guardan en el navegador local; no se agregan entre visitantes distintos.
